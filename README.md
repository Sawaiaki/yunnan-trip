# 云南八日 · 旅行手册

**https://sawaiaki.github.io/yunnan-trip/**

一份单文件的网页旅行手册：2026.09.30 – 10.07，长沙出发，丽江 / 泸沽湖 / 香格里拉 / 稻城亚丁 8 天 4 人。

## 功能

- **行程总览**：手绘线条艺术风格的路线地图，D1–D8 路线与徽章可点击，跳转对应天数
- **每日行程**：按天切换，含日程、提醒、景点、交通与天气
- **已预订**：机票 / 火车 / 酒店 / 包车等票券与住宿卡片，可新增、编辑（✎）、删除
- **费用结算**：记账 + 分摊人，自动汇总每人应付 / 应收
- **待办清单**：按人分组，勾选完成自动沉底，新任务置顶
- **多设备同步**：数据存 `localStorage`，自动与仓库 `state.json` 通过 GitHub API 双向同步（先登记者数据优先，后写覆盖）

## 技术

- 纯静态单文件 `index.html`，无构建、无依赖、无后端
- 地图为内联 SVG（`HANDMAP_SVG`），点击交互走原生 JS
- 部署：GitHub Pages，改动即推即生效

## 本地使用

直接用浏览器打开 `index.html` 即可（同步功能需要网络，本地打开时仅用 localStorage）。

## 目录

```
index.html   页面本体（含样式、SVG 地图与全部逻辑）
state.json   云端同步数据（由页面读写）
```
